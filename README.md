## 🚀 Projects

### [Deaf Sign Language Prediction](https://github.com/Mallikarjun-99-Reddy/Deaf-Sign-Language-Prediction)
A machine learning project that takes an image of sign language gestures and predicts the corresponding letter (A-Z) using Python.

- **Technologies:** Python, TensorFlow, OpenCV
- **Features:** Converts images of sign language into text (letters).
  
### [Tigor Fit Gym](https://github.com/Mallikarjun-99-Reddy/Tigor-Fit-Gym)
A gym management system with features like user registration, login, and fitness plan management. The system is built with **Java** and **JSP** for the backend and includes a basic user interface.

- **Technologies:** Java, JSP, Servlets, MySQL
- **Features:** User authentication, product catalog, and gym membership management.

### [Incident Log API](https://github.com/Mallikarjun-99-Reddy/incident-log-api)
A backend service to manage incidents with features for CRUD operations on incidents. Built with **Spring Boot** and **MySQL**.

- **Technologies:** Java, Spring Boot, MySQL
- **Features:** Create, Read, Update, Delete incidents via REST API.

### [Airport Lounge Access Management](https://github.com/Mallikarjun-99-Reddy/airport-lounge-access-management)
An airport lounge access management system that sends notifications after the 2-hour access limit. Built using **Spring Boot** and designed to integrate with email services.

- **Technologies:** Java, Spring Boot, MySQL, JavaMail API
- **Features:** User authentication, time-based notifications, and access control.
